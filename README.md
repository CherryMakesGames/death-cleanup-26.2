# Death Cleanup

A server-side Fabric mod that keeps each player's latest death location marked on BlueMap until the marker moves or the player removes it.

## Status

Death Cleanup is under active development.

## Requirements

- Minecraft 26.2
- Java 25
- Fabric Loader 0.19.3 or newer
- Fabric API
- BlueMap 5.22 or newer

## Building

Run:

```powershell
.\gradlew.bat build
```

The resulting JAR will be written to `build/libs`.
